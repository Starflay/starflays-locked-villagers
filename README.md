# Starflay's Locked Villagers

A small Fabric mod that locks a villager's trades after you view them for the first time.

Once you've opened a villager's trading menu, breaking or replacing its workstation won't reroll its trades. What you see is what you get.

Made for Minecraft 26.1.1.
